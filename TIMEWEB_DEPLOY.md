# Публикация на Timeweb Cloud App Platform

## Рекомендуемые настройки

- Тип приложения: Frontend
- Фреймворк: React
- Node.js: 20.19+ или 22 LTS
- Команда установки: npm install
- Команда сборки: npm run build
- Директория публикации: dist

## Перед загрузкой в репозиторий

```bash
npm install
npm test
npm run build
```

Если сборка прошла, проект готов к публикации.

## Важно про форму

Сейчас форма валидирует данные и показывает сообщение об успешной регистрации, но не отправляет данные в таблицу и не отправляет письма. Для этого нужно подключить backend, webhook или Google Apps Script.
